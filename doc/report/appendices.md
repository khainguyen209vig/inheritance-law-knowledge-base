# Danh mục phụ lục

Bộ phụ lục cung cấp thông tin đối chiếu và tái lập cho các quyết định đã trình bày trong báo cáo. Nội dung cốt lõi về mô hình tri thức, kiến trúc và kết quả tổng hợp vẫn nằm trong các chương chính.

| Phụ lục | Nội dung | Tệp |
|---|---|---|
| A | Fact contract và từ điển predicate | [appendix-a-fact-contract.md](appendix-a-fact-contract.md) |
| B | Danh mục Rule ID và trạng thái review | [appendix-b-rule-catalog.md](appendix-b-rule-catalog.md) |
| C | Mã CLIPS tiêu biểu và ánh xạ registry | [appendix-c-clips-mapping.md](appendix-c-clips-mapping.md) |
| D | Danh mục bộ tình huống thực nghiệm | [appendix-d-case-tests.md](appendix-d-case-tests.md) |
| D.1 | Case 1 – 227/2019/DS-ST | [appendix-d1-case-1.md](appendix-d1-case-1.md) |
| D.2 | Case 2 – 202/2021/DS-PT | [appendix-d2-case-2.md](appendix-d2-case-2.md) |
| D.3 | Case 3 – 64/2018/DS-ST | [appendix-d3-case-3.md](appendix-d3-case-3.md) |
| E | Schema CSDL, API contract và line protocol | [appendix-e-system-contracts.md](appendix-e-system-contracts.md) |
| F | Hướng dẫn thao tác và kế hoạch ảnh giao diện | [appendix-f-ui-guide.md](appendix-f-ui-guide.md) |
| G | Cài đặt, kiểm thử và tái lập | [appendix-g-reproduction-guide.md](appendix-g-reproduction-guide.md) |
| H | Công cụ usability test | [appendix-h-usability-instrument.md](appendix-h-usability-instrument.md) |
| I | Phân công và dấu vết đóng góp | [appendix-i-contributions.md](appendix-i-contributions.md) |

Không tạo Phụ lục J chứa toàn văn điều luật vì nội dung dài, dễ trùng lặp và có nguy cơ lỗi thời; báo cáo sử dụng trích dẫn tới nguồn chính thức. Không sao chép log kiểm thử thô thành Phụ lục K; log được giữ như artifact điện tử, còn Phụ lục G ghi lệnh, phạm vi và kết quả tổng hợp cần thiết để tái lập.
